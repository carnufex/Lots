# Suggested phrases

Read each one naturally. If you stumble, just record it again.

## Swedish

| id | phrase | why |
|---|---|---|
| sv-01 | Hallå hallå, fungerar det här? | short greeting (the one that went wrong) |
| sv-02 | Vilka containrar är trasiga just nu? | typical question |
| sv-03 | Hur många containrar kör vi, ungefär? | numbers |
| sv-04 | Visa loggarna för lots-shell de senaste tio minuterna. | technical names, numbers |
| sv-05 | Kan du förklara vad en kabelskarv är i ett fibernät? | longer question |
| sv-06 | Två av tolv containrar är inte friska, och databasen startade om för fyra minuter sedan. | a statement with numbers |
| sv-07 | Vilken site ligger närmast Sundsvall, och vad är den kopplad till? | place name, cmdb vocabulary |
| sv-08 | Starta om web-containern, tack. | a command |
| sv-09 | Nej, jag menade den andra. | very short, conversational |
| sv-10 | Vad hände med backupen i natt? | question with a common word that is easy to mishear |
| sv-11 | Kolla om Authentik och Longhorn mår bra, och säg till om något är konstigt. | product names |
| sv-12 | Sammanfatta mötet i tre punkter och lista vad som är på mig. | a meeting request |
| sv-13 | Hallå, hör du mig? Jag testar mikrofonen igen. | short, informal |
| sv-14 | Det var allt för nu, tack för hjälpen. | closing phrase |
