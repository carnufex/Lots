# Code of conduct

Lots is built by people who run systems for other people. Treat each other the way you would want to be treated on a bad on-call night.

- Be respectful and assume good intent. Disagree with ideas, not with people.
- Be welcoming to newcomers and to questions that seem basic: they usually point at missing documentation.
- No harassment, insults, discrimination or sexualised language or imagery, in any channel of the project.
- Do not publish other people's private information, and never post credentials, hostnames or data from real systems in issues.

Maintainers may edit or remove contributions and comments that break these rules, and may block people who keep breaking them.
Report a problem privately to the maintainers through GitHub (a private security advisory works for anything sensitive). Reports
are handled confidentially.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/), which you can read for more detail.
